# Class skills, dash, ultimate, K skill window, icons

User approved this design ("이대로 해줘"). Original names and art only (the reference screenshot is from another game; copy the layout, not its art/names).

Controls (combat mode, Alt): 1/2/3 = skills, 4 = heal, 5 = ultimate, left click = basic attack, double-tap space (in air) = 대시 점프 (common), K = skill window (works in and out of combat mode).
Client→server commands (keep the existing `/pipilife skill ...` handler): `skill attack 1|2|3`, `skill heal`, `skill ult`, `skill basic`, `skill dodge` (= 대시 점프).
Server→client cooldown chat message (client hides it and draws cooldowns): `<label> 재사용 대기 · <ms>ms` with labels exactly `스킬 1`, `스킬 2`, `스킬 3`, `회복`, `궁극기`, `평타`, `대시`.

Ultimate damage only applies once per target per cast. Allies (other players) are never damaged. Skills fire without targets (effects + cooldown) as now. Keep CombatStats.cooldown() (쿨감) applied to all cooldowns.

Skill window (K): chest-free client screen (no server menu needed; static data on the client must match this table). Layout like the reference: dark blue panels; left vertical tab strip with 4 tabs (전사 sword icon, 궁수 bow icon, 마법사 staff icon, 공통 boot icon); title bar "스킬"; three columns "기본 공격" (basic), "일반 스킬" (skills 1-3, 회복, and on the 공통 tab 대시 점프), "궁극기" (ultimate); each row = 32×32 icon in a framed square + name + key hint (e.g. "[1]"); scroll bars like the reference; hovering a row shows a tooltip: name, key, cooldown, coefficient ("공격력의 180%"), effect text. Opens on the tab of the held/equipped weapon's class. Esc/K closes.
Icons: 32×32 original pixel art PNGs in dev/pipi-travel/assets/pipitravel/textures/gui/skills/<id>.png (check the real asset path the pipi-travel build packs), generated by a node script dev/art/make-skill-icons.mjs (zlib PNG writer; python is broken — never use it): each icon a framed square background (class colour: warrior red/orange, archer green, mage purple/cyan, common sky blue) with a simple bold pictogram matching the icon idea. The combat HUD (CombatBar) shows the 5 skill icons (1,2,3,4,5) with cooldown overlays.
